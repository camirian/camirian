I build public, clean-room tools for **governable autonomy**: autonomous work that is replayable, reviewable, rollbackable, and held to evidence.

My broader technical base spans Physical AI, robotics simulation, MBSE (Model-Based Systems Engineering), cyber-physical systems, local open-model ensemble harnesses, and agentic verification workflows.

This profile is a sanitized publication surface. It highlights public-safe demos and clean-room case studies so the architecture, engineering depth, and observable system behavior are visible without exposing private workspaces, employer context, or unreleased implementation details.

---

### Core Focus

- **Governable Autonomy**: Run records, evidence packets, review surfaces, and bounded rollback for autonomous agents.
- **Fail-Closed Verification & Local Open-Model Ensembles**: Multi-model agreement-gated adjudication (`Qwen`, `Nemotron`, `DeepSeek`) and fail-closed RAG scorecards running headless on air-gapped edge nodes.
- **Robotics Simulation & Manipulation**: NVIDIA Isaac Sim 5.0, ROS 2 (Python & C++), Lula IK kinematics, OmniGraph bridges, and PhysX rigid-body dynamics.
- **Cyber-Physical Systems Architecture**: MBSE / SysML-style domain models, digital twins, and executable verification workflows.
