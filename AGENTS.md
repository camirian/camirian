# Camirian Profile Agent Instructions

This is a public profile and portfolio surface. Treat it as a sanitized
publication repo, not a planning workspace.

## Rules

- Keep claims public-safe, evidence-bounded, and aligned with linked public
  repositories.
- Do not add private strategy, private repo names that are not already public,
  customer notes, employer-adjacent material, secrets, credentials, or local
  workspace artifacts.
- Prefer short, verifiable portfolio updates over broad positioning changes.
- Before public-facing changes, check links and scan for private context.

## Definition Of Done

- The public narrative remains coherent from `README.md`.
- Linked projects are public-safe and still relevant.
- No private planning, unreleased implementation detail, or credential material
  was added.
